# แบบบันทึกทดลองบน DE10-Lite

สถานะ: **ยังไม่ได้ทดสอบบนบอร์ดจริง** ห้ามใช้ภาพ simulation เป็นหลักฐานภาพการทำงานจริง

ผู้ทดสอบ: __________  วันที่: __________  รุ่นจอ: __________

## การเตรียม

- [ ] ตรวจชื่อชิป 10M50DAF484C7G และบอร์ด DE10-Lite
- [ ] Compile ผ่านและไม่มี timing violation
- [ ] ต่อ USB-Blaster และจอ VGA แล้ว program ไฟล์ `.sof`
- [ ] SW9=0 แล้วเห็นหน้าพร้อมเล่น ไม่มีภาพสั่นหรือตัดขอบ

## การสาธิต

- [ ] KEY0 กดหนึ่งครั้งเลื่อนหนึ่งใบ กดค้างไม่เลื่อนซ้ำ และวนใบที่ 16 → 1
- [ ] KEY1 เริ่มเกมและเปิดการ์ดได้ การ์ดใบเดิม/ใบที่จับคู่แล้วเปิดซ้ำไม่ได้
- [ ] คู่ผิดเปิดประมาณ 1 วินาทีแล้วปิด คู่ถูกเปิดค้างและเพิ่มคะแนนครั้งเดียว
- [ ] คนเดียวเล่นจนได้ 8 คู่ แสดง COMPLETE และจำนวนครั้ง
- [ ] สองคนจับคู่ถูกได้เล่นต่อ ผิดจึงสลับตา
- [ ] แสดง P1 WINS, P2 WINS และ DRAW ในเกมที่เกี่ยวข้อง
- [ ] เปลี่ยน SW0 กลางเกมไม่เปลี่ยนกติกา
- [ ] KEY1 หลังจบกลับหน้าพร้อมเล่น เริ่มใหม่แล้วคะแนน/attempts เป็นศูนย์
- [ ] SW9 รีเซ็ตจากหน้าพร้อมเล่น ระหว่างเลือก ระหว่างเปิดสองใบ และหลังจบเกม
- [ ] รีเซ็ตไม่ทำให้จอหลุด sync

## หลักฐานสำหรับรายงาน

เก็บภาพบอร์ดและจอร่วมกันอย่างน้อยหน้าพร้อมเล่น, เปิดสองใบ, คะแนนสองผู้เล่น และหน้าจบเกม ถ่ายวิดีโอสั้นแสดงการกดจริง การรอหนึ่งวินาที และการสลับตา ใส่ไฟล์จริงใน `docs/hardware/` พร้อมชื่อผู้ทดสอบและวันที่
